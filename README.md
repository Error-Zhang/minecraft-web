# 我的世界 Web 版

## 🧱 项目简介
本项目是一个基于 **前端技术栈** 实现的类 **Minecraft** 风格沙盒游戏。  
项目采用 **Babylon.js + React + Electron** 构建前端（含桌面端），并配合 **.NET 10** 后端服务实现完整的世界渲染、数据交互与多人联机功能。

- **前端职责**：负责游戏渲染、UI 交互与桌面端打包。
- **后端职责**：负责世界数据管理、实时通信与 REST API 提供。

## 🧭 开发规范
请保持前后端分支命名一致，提交前说明更新内容。  
所有代码更新需通过审核后合并主分支。

示例：
```
feat/player-movement // 新增玩家移动功能
fix/chunk-rendering-bug // 修复区块渲染错误
refactor/sky-system // 重构天空系统
```
